## 🚀 Features

- **React project setup**
  - Built with **Vite**
  - Fast development server
  - Modern project structure

- **Component-based architecture**
  - Organized around reusable React components
  - Clear separation between app structure and styling

- **Frontend practice**
  - Focused on learning React fundamentals
  - Useful for experimenting with JSX, props, state or layout structure depending on the exercise

- **Educational Context**
  - Built as part of the **Epicode** learning path to practice React development in a modern environment
